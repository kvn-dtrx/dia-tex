# Dia-TeX

## Synopsis

This repository contains a collection of utils for LaTeX we regularly use across (*διά*) different LaTeX projects.

## Installation

``` shell
cd "${XDG_DATA_HOME}" &&
    git clone <repo-remote> &&
    cd dia-tex &&
        make ln
```
